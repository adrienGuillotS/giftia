Gigapixel Zipper 3.35 – Source Code
=====================================

FIRST TIME SETUP (do this once after extracting the zip):
----------------------------------------------------------
1. Right-click "Unblock_Files.ps1" and choose "Run with PowerShell"
   This removes Windows' "mark of the web" from all source files.

BUILD:
------
2. Open "Gigapixel Zipper.sln" in Visual Studio
3. Press Ctrl+Shift+B  (Build -> Build Solution)
4. Your exe appears in:
     Gigapixel Zipper\bin\Release\Gigapixel Zipper.exe

No NuGet packages to restore - the project uses only built-in .NET 4.8 libraries.
